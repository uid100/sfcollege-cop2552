The StringBuilder Class

While not as common as the String class, the StringBuilder class has its advantages. The biggest advantage is that you can change the contents of a StringBuilder object.

Remember that String objects are not changeable once the contents have been set. If you are in need of changing the contents of the String object, you may want to consider using a StringBuilder object instead.

StringBuilder objects are more efficient than String objects because if you change the contents of a String object, the current String object is destroyed and the system invokes the garbage collection utility. Then a new String object is created with the new contents. With the StringBuilder object, there is no need for a destructor and/or garbage collection.

No new memory need be allocated.

The contents are simply updated.

Using Tokens in Strings

Using tokens and delimiters is quite common in industry. You have likely used tokens and delimiters if you've imported or exported a file from the internet or site.

In Microsoft Excel, you can export your file using a .csv file (comma separated values file) meaning a comma will be the delimiter between the tokens (or the values stored in each cell). Often times, you may choose the delimiter to be used when exporting files. Delimiters are usually special characters that are not found in the data stored within the file.

Likewise, if you receive an exported .csv file with a given delimiter, the program importing the file will know what to do with the values between the delimiters.

We've now reached our first data structure in Java - the static array. Remember, with static arrays the size of the array may not change once created.

Arrays in Java

The concept of an array is the same in Java as is the other C-based languages you've studied. There is a slight syntax difference.

To declare an array of 10 integers, you would write:

                int arrayA[10];                 // in C++
is now: 
                int[] arrayA = new int[10];     // in Java

 

As far as accessing the array elements, updating values within an array, displaying values, sorting and searching arrays, passing arrays to methods, etc... you should feel right at home with arrays in Java. They behave just as they did when you studied arrays in C++ and C#.

Advantages of using Arrays in Java

One nice thing about Java that you did not experience with C++ is that Java will automatically check array boundaries for you. An exception will be thrown if the user (or program) attempts to go outside the array boundaries. C++ will allow you to go beyond array boundaries, but Visual Studio will not allow you to do so.

Similar to C#'s foreach, Java also has an enhanced for loop that works ideally with arrays. For example, if you would like to add the values stored in the elements in an array:

            int sum = 0;
            for (int num : arrayA)
                sum += num;

This for loop will iterate as many times as the number of elements within the array arrayA. If arrayA has 10 elements, the for loop will iterate 10 times.

Of course, the first iteration will add the contents of the 0 element to the variable sum, the second iteration will add the contents of element 1 to the variable sum, and so on, until all 10 elements have been added to the variable sum.

Arrays of Objects

While the concept of multiple objects instantiated from a single class has been discussed in previous courses, it has been rarely used. It is time to experience this widely used practice.

For an array to hold multiple objects, you would simply declare an array of the data type of the class - that is, the class name. Remember, when you create a class, you are creating a new data type.

For demonstration purposes, let's keep the class contents small, but this will work even for the largest of classes.

Example: SuperHero Game

We are writing a game. Say we have a class named SuperHero. The superheros will have a name and a superpower. If you think about it, some superheros have multiple powers so we could have an array to store each power for each superhero! But, for this lesson, we will just assume one power per superhero.There is also much more information that we could store for each superhero (such as human name, gender, weapons, source of power, antithesis supervillian, etc...), but again, let's keep this small.

            public class SuperHero {
                String superName;
                String superPower;
        
                //class methods here
            };

Let's say when the game begins, the player is given a choice and will select an imminent disaster. Based on the imminent disaster chosen, we would program the game to select appropriate superheroes and retrieve this data from the database.At this time, we would populate an array of superheros from which the player will select one superhero based on the current need. Meaning, if a supervillian was attempting to blow up the moon, Aquaman may not be an appropriate choice. Likewise, if a supervillian plans on destroying Atlantis under the sea, Batman may not be an appropriate choice.

Let's say we will give the player 5 superhero options in which to choose to overcome the imminent disaster. The player may change the superhero throughout the game based on the situation involved for a level.

Let's say the player has chosen for the imminent disaster the use of nuclear weapons to destroy a populous city and will store these in an underwater facility.

To populate the array, it would look something like this:

                SuperHero[] supers = new SuperHeros[5];

 

Let's say the superhero information is stored in a database table. (We will soon learn how to connect to a database). We download the information:

  • supers[0] would contain superName = Superman and superPower = strength
  • supers[1] would contain superName = Spiderman and superPower = spidey sense
  • supers[2] would contain superName = Batman and superPower = genius intellect
  • supers[3] would contain superName = Aquaman and superPower = underwater ability
  • supers[4] would contain superName = Flash and superPower = speed

 

Now the user is able to select a superhero and begin playing the game.

The ArrayList Class

Just like the List class used in C#, Java has a data structure called the ArrayList. The main difference between an array and an arraylist is an arraylist is able to adjust the size of the list depending on the number of items being stored within it. In a way, an arraylist is a dynamic array in that the size is adjustable.

The syntax is very similar to C#:

 

            List  nameList = new List();                 //C# syntax

 

 

            ArrayList nameList = new ArrayList();        //Java syntax

 

Also, import java.util.ArrayList; is needed in order to use the ArrayList class in Java.

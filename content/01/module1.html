The goals for this week:

  • install and configure Java and Eclipse
  • start creating Java solutions and using the Eclipse IDE

 

This course is designed to be an intermediate object-oriented programming class. From that description, there is an expectation that the student is comfortable writing code and specifically, creating classes and objects. From a professional engineering perspective, you will find that the language is secondary to the fundamental OOP principles.

So while we will be introducing and highlighting some syntax which is peculiar to Java, this should not be viewed as an introductory programming class. Instead, we will be building on the knowledge that you already have. The textbook currently assigned to to the class does a good job of supporting this goal and has a lot of very good examples. It is recommended that you try the examples in the book as you study. The more code that you write, the easier (and more fun!) it will be.

Use the book to introduce concepts that are unique to the language, but keep your mind open to the idea that most of the topics apply to any object-oriented language.

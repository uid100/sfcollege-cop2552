JavaFX and the Graphical User Interface (GUI)

As you have likely noticed, the Java platform allows you to create programs and program components that have many different user interfaces

We have learned in a Java console application, the user interface is a command-line interface that displays character input and output.  While many platforms have a black screen to indicate a command-line interface, the default for Eclipse is a white background.  The color doesn't matter, the fact remains that console applications use a command-line interface.

By contrast, the application may have a graphical user interface (GUI) that is displayed in a window. These windows can also be programmed to display output to a user in a browser window as well - as we will see in the next chapter.

Using JavaFX

You have used GUIs in previous programming courses. You have learned and used programmed controls, properties, and events. As in other programming languages, Java has a library that allows the creation of a GUI application called JavaFX. There are also several different GUI libraries and frameworks available, such as AWT and Swing, to name a few.

In JavaFX, the basic controls introduced in this chapter should be familiar to you.

Label control is an object that displays text.

TextField control is an object that displays a text box in which users enter text.

Image control is an object that displays an image.

Button control is an object that displays a command button for users to click to trigger an event.

JavaFX also uses something called stages and scenes.

While you may think immediately of the theater, these are used somewhat similarly. The stage is the form window. The scene is the group of controls placed on the stage.

There is a protocol when you are creating a scene.  The program will:

  1. create the controls that will be used.
  2. create a layout container to add the controls that have been created.
  3. create a Scene object to add the layout container.
  4. add the Scene object to the program stage.

A program demonstrating these steps will follow.

Creating a Control

Button Control

To create a button control: Button btnCalculate = new Button("Calculate");

This line of code will create a Button object named calcButton that will display the text Calculate. In essence, the Button class constructor is called which will set the name property and text property for this button control.

Creating a Control

Button Control

To create a button control: Button btnCalculate = new Button("Calculate");

This line of code will create a Button object named calcButton that will display the text Calculate.  In essence, the Button class constructor is called which will set the name property and text property for this button control.

Label Control

A label control is very similar: Label lblDisplay = new Label("Click the Calculate button to see your body mass index");

This line of code will create a Label object named lblDisplay that will display the text above.  The Label class constructor is called.

TextField Control

A TextField control: TextField txtHeight = new TextField();

A TextField object is instantiated.

Image Control

An Image control:

Image imgBlackHole = new ImageView("file: blackhole.jpg"); ImageView imgBH = new ImageView(imgBlackHole);

An ImageView object is instantiated.

Layout Containers

Layout containers are used to arrange the controls created previously on the form or screen.

There are three containers defined in this chapter:

  • HBox displays controls in a single horizontal row
  • VBox displays controls in a single vertical column
  • GridPane displays controls in a grid with both rows and columns

To place the above controls (Button, Label, and TextField) onto a layout container:

HBox hbox = new HBox(txtHeight, lblDisplay, btnCalculate); Scene scene = new Scene(hbox);

VBox vbox = new VBox(txtHeight, lblDisplay, btnCalculate); Scene scene = new Scene(vbox);

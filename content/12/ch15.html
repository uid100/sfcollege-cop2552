Chapter 15 Databases

 

As you have seen, much of this course has been a review of material which you have already learned, and the intent is not to introduce concepts but to put them in the context of the Java programming language and environment.

A database design and management discussion is the same. Here we will apply these concepts and leverage those skills but also sharpen them with new examples and more practice.

Additionally, the selected textbook is an excellent reference book, but also a starting point. Use the examples to get your projects started, but don't be limited by them. In many ways this book's value may become more apparent to return to for information, rather than reading the chapters sequentially.

 

Structured Query Language

Java Dabatabase Connectivity supports interfaces to different databases. You are probably already aware that as standardized as SQL statements appear, there is still significant difference between Oracle, SQL Server, SQLite, MySQL and others. Keep these questions in mind while you are looking through the material. How might you need to modify your code for switching between database platforms? Can your code support multiple installations with minimal or no changes? Could you write a small utility to test this?

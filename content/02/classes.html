Encapsulation

Did you notice that the main() function is defined within class? Java is a completely object-oriented language.

While the concepts of encapsulation are the same in Java as they have been within C++, C#, and Python, the syntax is slightly different as you have likely noticed. Instead of writing:

int main() as you did in C++,

static void Main() as you did in C# (Visual Studio wrote this for you),

you'll notice that Java uses: public static void main(String[] args)

again, Java is completely OOP, which is why even main() gets a public accessor within the class. If you're curious about what the static keyword is all about, we will go into greater detail when we reach chapter 6. For now, static just means that the variable or method belongs to the class itself - NOT to the object instantiated from the class.

 

Since main() is where execution begins with each program, it is able to run from within the class without having an object instantiated. The static variable/method is created once in memory and is used throughout the program.

 

There are times when you do not want a separate variable or method to be created for each object. You want the same memory location to be accessed. For a simple example, think of a counter. Perhaps you are counting the number of times a database table was modified. It doesn't matter which object updated the database table, you want to keep a total aggregate count of database updates. In this case, you would consider using a static variable. It has one memory location and every time an object - regardless of which object - updates the database, this static counter would increment.

The same holds true for methods. If you have a method that will do the same sequence of instructions for each object instantiated, you may consider using a static method. In this case, main() is considered a static method of the class and may execute without being called by an object of the class.

 

Packages and import Statements

As you learned to add additional components and definitions to your programs:

  • #include preprocessor statements in C++, and
  • Using Using preprocessor statements in C#,
  • Similarly, Java uses the import statement.

 

There are many, manyimport statements within Java. These are additional classes that contain components, definitions, and drivers that will allow your program to function in the manner needed.

As with other languages and compilers, Eclipse and the JDK (Java Development Kit) will automatically import the java.lang package which contains some of the basic data types and commands used in Java programs. Your textbook gives you a sample of some of the standard packages used in Java. See Table 3-2 in Chapter 3 in the text.

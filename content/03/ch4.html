Chapter 4 Decision Structures

 

Conditional Execution Statements

Since this is likely the 5th programming course (maybe the 6th or more!) you've taken - depending on your course sequence - it should go without saying that the decision structure within a C-based language is something in which you should be very familiar.

Java is a C-based language - just like C++ and C# - and the if/else and switch statements have the exact same syntax and functionality as other C-based languages.

If you are unsure about the decision structures - please go through this chapter carefully. At this level, you should feel very comfortable with if/else statements.

 

The Random Generator

While the concept of the random generator in Java is the same as with other C-based languages, there are a few syntactical differences.

At the top of the program add
import java.util.Random;
an object of the Random class is created (as used in C#) before any function calls to obtain a random number
Random rand = new Random();
the call to obtain a random value is object.method(parameters)
int value = rand.nextInt(6) + 1;

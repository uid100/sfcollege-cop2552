Chapter 5 Loops and Files

 

Conditional Execution Statements

By now, I'm sure it comes as no surprise that there are a lot of similarities between Java and the other C-based languages you have learned. Guess what? Loops are no different!

The functionality and syntax is exactly the same as you learned in C++ and C#.

 

Java:

loop structures
while loop: 
while ( a < b )
{
    // loop contents
}
do-while loop: 
do
{
    // loop contents
}  while ( a < b );
for loop: 
for ( int a = 0; a < b; a++ )
{
    // loop contents
}

 

File I/O

The concept of file maintenance remains the same in Java.

  • You must open the file before you may read from or write to the file.
  • You must test if the file opened properly.
  • After the program has completed its use for the file, the file must be closed.

That said, there are a few syntax differences of which to be aware:

  • add: 
    import java.io.*;           // needed for file use
import java.util.scanner;   // needed for input file
  • to write to an output file, you must create an object of the PrintWriter class. (Similar to the StreamWriter class in C#) 
    PrintWriter outputFile = new PrintWriter("filename.ext");
  • to write a line to the output file, 
    outputFile.println("Hello");
  • to read from an input file, the program will use the Scanner class as used with the keyboard input, but instead of Scanner(System.in) , the program will place the file name in the argument list: 
    Scanner inputFile = new Scaner("filename.ext");
  • to read the next line from the input file: 
    String line = inputFile.nextLine();   // contents of the line of input will
                                      // be stored in the variable: line
  • to read to EOF (end of file): 
    while (inputFile.hasNext());   // returns true if more data
                               // exists in the input file
  • to test if a file was opened properly: (end of file): 
    File file = new file(filename);
if (!file.exists())
{
    System.out.println("Error: file not open");
    System.exit(0);
}

 

Be aware that if the program uses the PrintWriter to open a file that already exists, the contents of the file will be deleted.

It's always a good idea to check if the file exists before opening the file. If it does exist, the program should prompt the user that the file will be overwritten and allow the user to exit or give a different filename without throwing an exception.
